# CRUD Studio

A simple and modern CRUD (Create, Read, Update, Delete) web application
built with **Node.js**, **Express.js**, and **MySQL**. It lets users
add, view, edit, and delete user records through a web interface.

## Features

-   **Create:** Add a user with a name and email address.
-   **Read:** View all registered users in a table.
-   **Update:** Edit an existing user's details.
-   **Delete:** Remove a user record after confirmation.
-   **Responsive interface:** A layout designed for desktop and mobile
    screens.
-   **Midnight Obsidian theme:** Dark charcoal styling with lime-green
    accents.

## Tech Stack

-   **Frontend:** HTML, CSS
-   **Backend:** Node.js, Express.js
-   **Database:** MySQL
-   **MySQL driver:** `mysql2`

## Prerequisites

Install the following before running the application:

-   [Node.js](https://nodejs.org/)
-   MySQL Server
-   MySQL Workbench (optional, for managing the database)

## Installation and Setup

### 1. Clone or download the project

If the project is hosted in a Git repository, clone it:

``` bash
git clone <repository-url>
cd crud-app
```

Otherwise, open a terminal in the project folder.

### 2. Install dependencies

``` bash
npm install
```

If the dependencies are not listed in `package.json`, install them with:

``` bash
npm install express mysql2
```

### 3. Create the database

Open MySQL Workbench and run:

``` sql
CREATE DATABASE crud_db;

USE crud_db;

CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100),
    email VARCHAR(100)
);
```

### 4. Configure the database connection

Open `server.js` and update the MySQL connection settings with your own
credentials:

``` javascript
const db = mysql.createConnection({
    host: "localhost",
    user: "root",
    password: "YOUR_PASSWORD",
    database: "crud_db"
});
```

Replace `YOUR_PASSWORD` with your MySQL password. Do not publish your
real database password in a public repository.

### 5. Start the application

From the project folder, run:

``` bash
node server.js
```

When the server starts successfully, open:

``` text
http://localhost:3000
```

Keep the terminal running while using the website.

## How to Use

1.  Open the home page at `http://localhost:3000`.
2.  Select **Add User** to create a user by entering a name and email.
3.  Select **View All Users** to see the saved records.
4.  Use **Edit** beside a record to update its details.
5.  Use **Delete** to remove a record. Confirm the browser prompt to
    proceed.

## Application Routes

  Method   Route           Description
  -------- --------------- -----------------------------------
  GET      `/`             Displays the home page
  GET      `/add.html`     Displays the Add User form
  POST     `/add`          Creates a user
  GET      `/users`        Displays all users
  GET      `/edit/:id`     Displays the edit form for a user
  POST     `/update/:id`   Saves changes to a user
  POST     `/delete/:id`   Deletes a user

## Troubleshooting

-   **Database connection failed:** Check that MySQL Server is running
    and the host, username, password, and database name in `server.js`
    are correct.
-   **Cannot find module:** Run `npm install` in the project folder.
-   **Port 3000 is already in use:** Stop the other process using the
    port or change the port in `server.js`.
-   **Styles are not visible:** Confirm `public/style.css` exists, then
    refresh the page with `Ctrl + F5`.
